# Patrones de diseño en Java

Ejercicios prácticos de **patrones de diseño** en Java. Cada patrón tiene un ejemplo (`Ejemplo.java`) y un reto (`problema.txt` o `reto.txt`).

## Patrones incluidos
- **Decorator**: notificaciones combinables (email, SMS, cifrado, reintentos)
- **Adapter**: adaptar una librería externa a una interfaz propia
- **Factory + Strategy**: métodos de pago intercambiables (efectivo, tarjeta, cripto)
- **Template Method + Observer**: proceso de checkout con observadores (email, analítica, auditoría)

## Cómo ejecutar
Compila y ejecuta el `Ejemplo.java` de cada carpeta desde el IDE.

## Proyecto de aprendizaje
Práctica de diseño orientado a objetos.
